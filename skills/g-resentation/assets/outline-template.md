- **总页数**：

> 确认后把状态改成"已冻结"，并立刻跑 `snapshot.py <deck> outline` 存基线。冻结后增删页必须用户点头。

---

下面是一页的格式，照它从 P01 往后写，写完删掉这段示例。

```markdown
## P01 标题（说观点，不是分类名）

1. **想表达的意思**：这一页要让观众理解什么，一句话。
2. **屏幕文字**：实际放上页的精简文案，不是讲稿。
3. **数据与来源**：对应文件、页码或链接；没有就写"无"。
4. **图片素材**：`assets/media/` 里的文件名及用途；缺就写"待补充"。
5. **建议布局**：文字、图、图表怎么摆。
6. **演讲备注**：不必显示在屏幕上的补充。
```

---

## 自检

- [ ] 没有两页讲同一件事
- [ ] 没有一页塞三件事
- [ ] 没有为凑页数硬加的章节
- [ ] 每个数字都标了来源，或写着"待补充"
- [ ] 标题说的是观点，不是分类名

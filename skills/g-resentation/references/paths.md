# 选路线、样张与制作

## 判据

| 用户的实际说法 | 走哪条 |
|---|---|
| 站台上讲、要动画或交互、现场要跳页 | HTML Slides |
| 发群里或邮件里，别人自己看，之后不改 | 出图片，再合成 PDF |
| 同事要接着改内容、换数据，要给别人编辑 | 可编辑 PPTX |
| 既要讲、又要给人一份能改的 | 网页版 + PDF；或封面与重点页出图，内容页做可编辑 |

判据来自 `brief.md` 第四部分，不用再问一遍。

## 先猜后确认

不要问"你要哪种"。看完 brief 直接给判断和理由，把否决权留给用户：

> 按你说的（内部周会、五页、发群里自己看），我打算做网页版——能翻页、能给链接，也不用他们装软件。先出三页样稿，不合适再换。

这样说错了他会立刻纠正，比让他选省事，也不容易被"可编辑听起来更高级"带偏。

## 三条路怎么调

### HTML Slides

用 `references/prompts.md` 的 **P3**。

- `frontend-slides`：固定 16:9 画布，等比缩放，风格预览，普通分享和演讲首选。
- `guizang-ppt-skill`：横向翻页，带演讲者视图和观众屏，两套设计语言（杂志风 / 瑞士风）。

硬要求：标题正文用真 HTML 文字；图片、字体、脚本打包在本地，不依赖 CDN；导出 PDF 备用稿，动画页在 PDF 里也要有关键信息。

两个技能都没装也没关系：直接手写单文件 HTML，固定 16:9 舞台、键盘翻页、打印样式这三件事自己实现就行，本流程不依赖它们的内部结构。

### 出图片

用 **P4**，逐页生成 16:9 整页图，按 `01_封面.png`、`02_标题.png` 命名，不要拼长图。文字直接画进图里，字号要够投屏读。

没有 `imagegen` 就换别的出图工具，实在没有就退到 HTML 路线、截图导出 PNG；别拿一段"我无法生成图片"糊过去。

这条路的改造成本最高：改一个字都要重生成整张，风格也最容易漂。所以样张三张尤其重要，三张风格稳了再放量。

用户后面还要改，就接 **P5** 走 `ppt-master` 还原 PPTX；提前说清这是有损还原，文字未必全部可编辑。

### 可编辑 PPTX

用 **P6**，交给 `ppt-master`（上游 `hugohe3/ppt-master`，需自行安装）。它本身要求先做三页样稿，与本流程一致，直接沿用。

调用要点：

1. 先确认解释器能导入它的依赖，导不进去就让用户装，别写死任何人的虚拟环境路径：

```bash
PY=$(command -v python3 || command -v python)
"$PY" -c "import pptx, yaml, pathops, uharfbuzz" || echo "缺依赖：pip install -r <PPT_MASTER_DIR>/requirements.txt"
```

2. 再跑完整性校验，非零立刻停，不修不绕过：

```bash
"$PY" "<PPT_MASTER_DIR>/scripts/attribution_guard.py"
```

3. `<PPT_MASTER_DIR>` 是它安装后的技能目录，自己解析，不要照抄文档里的示例路径。
4. 按它自己的 `workflows/routing.md` 选一条 route（一般是 Generate PPTX），只读被选中的那份流程。
5. 把 `outline.md` 和 `assets/` 作为源导入它的项目，不要重新编一套大纲——页码锁定对它有约束力。
6. 需要公司模板时，把 `.pptx` 模板一起交给它，要求沿用母版和版式。

没装 `ppt-master` 就别承诺 PPTX：退到 HTML 或出图，并在交付说明里写清"本次未生成可编辑 PPTX，原因是未安装对应工具"。

## 样张三页怎么挑

封面、信息最多的一页、图表或流程最复杂的一页。三类重合时另挑一页，保证覆盖不同排版。

给真产物，不给截图：

- 网页版给能本地打开、能真翻页缩放的 HTML
- 出图给三张原始分辨率的 PNG
- PPTX 给能直接打开的 `.pptx`

问一句："这三页的方向对不对，哪里不对？"不要问"您看怎么样"。

## 分批推进

每 10 页一批，一批出完报一句"P11–P20 好了"，不打断、不逐页请示。只在某页确实做不出来（素材缺失、内容矛盾）时停下来问。

## 风格

不单设一步。交给制作环节：给参考图比给形容词有效；有公司模板或品牌色就一起给，并要求沿用母版。有参考图时先跑 **P2** 拆出配色、字体、字号层级，产出风格说明再进制作；没有就跳过。同一份内容换路线时，风格跟着新路线的默认走，不追求跨路线一致。

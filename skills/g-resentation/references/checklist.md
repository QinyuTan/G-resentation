# 验收、留版与交付

## 四类验收

逐项过，不通过就修，修完重新检查该项。

### 一、内容

- 错字、漏页、重复页
- 页序与 `outline.md` 的编号一一对应（P01 就是第一页）
- 数字、单位、时间、来源与 `assets/sources/` 一致
- 标题说的是观点，不是分类名
- 没有为凑页数加的章节

### 二、画面

- 文字没有被图或色块挡住
- 图片不变形（按原比例显示）
- 每页只有一个重点，一眼能看出来
- 同一级标题字号一致，没有忽大忽小
- 页边距一致，没有贴边

### 三、操作

网页版必须用内置浏览器真开一遍，不看截图：

- 左右键翻页、上一页/下一页按钮、全屏、页码都正常
- 缩放窗口时不拉伸、不裁切、不溢出
- 目录或概览能跳到指定页
- 动画能回到初始状态，能重复演示
- 断网重开后图片、字体、脚本都还在

PPTX 只能在 PowerPoint 里人眼过一遍；图片版逐张看过即可。这三条都要在交付说明里写清实际做到了哪一步。

### 四、备用稿

- PDF 与最终版一致，一页幻灯片对一页
- 动画页在 PDF 里保留完整关键信息
- PDF 里没有演示控制按钮、空白页、隐藏内容

## 留版

只在两个时机存到 `versions/`：逐页稿确认后（`v01-outline`）、交付前（`v02-final`）。大改前额外存一版，命名带日期：`v03-20261110`。

只存 `outline.md`、`brief.md` 和 `out/` 里的成品，不存中间稿；素材不进版本，避免文件夹翻倍。

## 交付说明

一段话讲清三件事：

1. 从哪个文件打开（入口 HTML / PDF / PPTX 的完整路径）
2. 需要什么条件（本地打开即可 / 要起本地服务 / 要装字体）
3. 已知限制（哪几页是图片、哪些字没法编辑、哪条素材是占位）

做不到的地方如实写，不把图片标注成可编辑，不把没验的说成验过。

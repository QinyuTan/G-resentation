## P01 封面：客户续约率下降，先做什么

1. **想表达的意思**：这是一次诊断，不是一次报数。
2. **屏幕文字**：主标题；副标题「近三季度流失结构复盘」；日期。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：左下角大标题，右上留白。
6. **演讲备注**：开场直接给结论，别铺垫。

## P02 近三季度续约率下滑 6.4 个百分点，几乎全来自同一类客户

1. **想表达的意思**：把"整体在跌"变成"跌在谁身上"。
2. **屏幕文字**：整体续约率 91.2% → 84.8%；其中中小客户贡献了 5.7 个百分点。
3. **数据与来源**：`assets/sources/` 续约明细导出，取近三个季度。
4. **图片素材**：待补充，用一个折线加分组柱。
5. **建议布局**：左侧一句话结论，右侧图。
6. **演讲备注**：说明口径是合同到期日，不是签约日。

## P03 流失客户在到期前 90 天，都有一个共同信号：没有人的名字挂在上面

1. **想表达的意思**：问题出在交付后的空档期。
2. **屏幕文字**：到期前 90 天内主动联系记录为零的客户，流失率是其他客户的 3.1 倍。
3. **数据与来源**：同一份明细，交叉联系记录表；比例为内部统计。
4. **图片素材**：无。
5. **建议布局**：一句结论 + 三条行为证据。
6. **演讲备注**：强调这是相关性，不是因果，试点就是为了验证因果。

## P04 试点切三刀：责任到人、90 天节点、按周看信号

1. **想表达的意思**：给出最小可执行的改动。
2. **屏幕文字**：一客户一负责人；到期前 120/90/60 天各一次固定动作；每周看一次联系覆盖率。
3. **数据与来源**：方案为我们的建议，非行业标准。
4. **图片素材**：无。
5. **建议布局**：三步横向时间轴。
6. **演讲备注**：明确试点只覆盖 20 家，不影响现有服务节奏。

## P05 一个季度后看两个数：联系覆盖率与到期续约率

1. **想表达的意思**：把"该不该继续"提前定义好。
2. **屏幕文字**：覆盖率从 41% 提到 80%；续约率回升 3 个百分点即判定有效。
3. **数据与来源**：基数为上季度实际值；目标值为建议阈值。
4. **图片素材**：无。
5. **建议布局**：两个大数字并排，下面一行判定规则。
6. **演讲备注**：留两分钟给口径讨论，别在会上争细节。

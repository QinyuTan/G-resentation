# 逐页稿：需求澄清内部培训

- **标题**：把需求问清楚，比做得好更重要
- **总页数**：6
- **状态**：已冻结

## P01 封面：把需求问清楚，比做得好更重要

1. **想表达的意思**：这门课不教工具，教提问。
2. **屏幕文字**：把需求问清楚，比做得好更重要；90 分钟学会三件事。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：米色底，衬线大标题，左侧一道短色条。
6. **演讲备注**：开场问一句"上一次返工是从哪一步开始的"。

## P02 学完你能做到什么

1. **想表达的意思**：把收获说成可检验的能力。
2. **屏幕文字**：判断值不值得做；问出真正要什么；做完能说清对不对。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：三条纵向编号列表。
6. **演讲备注**：每条配一个学员熟悉的项目例子。

## P03 三步法：定档位、要答案、定验收

1. **想表达的意思**：顺序不能倒，先定验收再动手。
2. **屏幕文字**：STEP 1 定档位 / STEP 2 要答案 / STEP 3 定验收。
3. **数据与来源**：方法来自项目返工复盘，非行业标准。
4. **图片素材**：无。
5. **建议布局**：三栏等宽卡片，顶部一道色条。
6. **演讲备注**：强调三步是顺序，不是清单。

## P04 同一句话，两种问法

1. **想表达的意思**：让对方必须给出唯一答案。
2. **屏幕文字**：左"你想要什么样的"；右"给谁看、听完做什么决定、只能记住哪句"。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：左右对照，左灰红、右灰绿。
6. **演讲备注**：现场让两个人各演一遍，差别立刻听出来。

## P05 四个常见错误

1. **想表达的意思**：把返工原因说成表，便于自查。
2. **屏幕文字**：替对方假设 / 先做后想 / 不问验收 / 全都答应，各配代价。
3. **数据与来源**：来自过去一年项目的返工记录（内部）。
4. **图片素材**：无。
5. **建议布局**：三列表格：错误、表现、代价。
6. **演讲备注**：让学员举手认领自己犯过的。

## P06 现场练习：三道题

1. **想表达的意思**：把方法用在一句话需求上。
2. **屏幕文字**：三句真实需求 + 每题一个提问方向。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：三条横排卡片，下方一行练习说明。
6. **演讲备注**：第 3 题用来区分"改"和"重做"，是全场最容易被忽略的一点。

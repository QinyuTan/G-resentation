# 逐页稿：AI 变化的内部宣讲

- **标题**：AI 这一年的变化，对我们意味着什么
- **总页数**：8
- **状态**：已冻结

## P01 封面：AI 这一年的变化，对我们意味着什么

1. **想表达的意思**：今天不讲榜单，只讲下一步做什么。
2. **屏幕文字**：主标题 + "不讲行业榜单，只讲一件事：下个季度我们先用它做什么"。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：深色底，超大标题，底部一行元信息。
6. **演讲备注**：开场先承认大家听腻了 AI，这是全场信任的起点。

## P02 不是要不要用，是先在哪儿用

1. **想表达的意思**：把争论从"要不要"挪到"从哪开始"。
2. **屏幕文字**：模型三个月换一次，我们等不起"全公司都准备好了"。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：整页一句大字，下面一行小字解释。
6. **演讲备注**：这一页要停顿三秒，让话落地。

## P03 外面发生了什么：三件事

1. **想表达的意思**：给三条硬事实，不做行业综述。
2. **屏幕文字**：从演示到交付、从单个到成群、从通用到分层。
3. **数据与来源**：对应 2026 年 11 月的公开动态（详见对外版 P03、P04、P09）。
4. **图片素材**：无。
5. **建议布局**：三栏，大编号。
6. **演讲备注**：每条只讲一句，别展开，展开就变成行业课了。

## P04 客户已经在问我们了

1. **想表达的意思**：把外部压力翻译成同事能感知的场景。
2. **屏幕文字**：三个真实提问——你们用 AI 吗、有没有案例、能不能更快。
3. **数据与来源**：来自销售与交付的日常反馈，非统计。
4. **图片素材**：无。
5. **建议布局**：三行，右侧标注被问的场合。
6. **演讲备注**：说出"我们答不上来"，比讲趋势更有冲击。

## P05 手上有三个能马上用的

1. **想表达的意思**：把 AI 从抽象变成三个具体入口。
2. **屏幕文字**：材料与汇报、信息整理、代码与配置，各配一句收益。
3. **数据与来源**：收益为经验估计，非实测。
4. **图片素材**：无。
5. **建议布局**：三栏，A/B/C 大编号。
6. **演讲备注**：强调共同点——高频、可回滚、好坏一眼可见。

## P06 一个 90 天试点

1. **想表达的意思**：给出可执行的最小承诺。
2. **屏幕文字**：第 1–30 天选场景定评估；31–60 天写成规范；61–90 天看两个数。
3. **数据与来源**：周期为建议，按实际情况调整。
4. **图片素材**：无。
5. **建议布局**：三段横排。
6. **演讲备注**：明确不新增人头、不新买工具，降低抵触。

## P07 不做的代价

1. **想表达的意思**：把"不做"也标上价格。
2. **屏幕文字**：不是浪费钱，是每次客户问起只能回答"在探索"。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：整页一句大字。
6. **演讲备注**：不吓唬人，只陈述一个季度后的落差。

## P08 所以：三个人，一个场景，九十天

1. **想表达的意思**：用一个具体请求收尾，而不是"大家加油"。
2. **屏幕文字**：下周一开始，三个人一个场景，九十天拿结果说话。
3. **数据与来源**：无。
4. **图片素材**：无。
5. **建议布局**：左侧超大结论，下方一行报名方式。
6. **演讲备注**：说完就停，不解释，等举手。
